AWS Amplify Gen 2 · Module 01

Learning Log

A small app built module by module to learn Amplify Gen 2: static hosting first, then Cognito auth, then a REST API backed by API Gateway, a Go Lambda, and DynamoDB.

What's being built here

  • Module 00 — Setup. AWS credentials, CDK bootstrap, the Amplify sandbox.
  • Module 01 — Static site. This page: served by Vite, deployed by Amplify Hosting.
  • Module 02 — Auth. Sign up, confirm, sign in with Cognito — hand-built, no UI kit.
  • Module 03 — Data. A REST API (API Gateway → Go Lambda → DynamoDB), scoped per signed-in user.
  • Module 04 — Hardening. Branch deploys, least privilege, observability.
